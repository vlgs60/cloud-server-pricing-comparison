## 云服务器定价由哪几部分组成

一份完整的云服务器账单分三块：实例、磁盘、带宽。实例配置费按 vCPU 和内存计价，是账单里最大的一块，也是各家价格表主要展示的部分；磁盘按容量和类型（系统盘、数据盘）另算；公网带宽单独计费，也是新手最容易意外的地方——很多人比完实例价格就下单，月底发现带宽和流量占了不少。

带宽单独收费这一点各家通用：阿里云把“云服务器配置费用 + 磁盘价格 + 公网带宽价格”列为价格的三部分，Azure 也明确对出口流量收取标准费用。所以看价格表记住一条：表里的月价只是实例本身，不是最终账单。

另外两个看表常识：月度价格按730小时评估是行业常见基准，Azure 官方价格页明确这样标注，做按量成本试算可以直接用这个数；价格通常不含税，跨境购买还涉及汇率换算。

## 按量付费和包年包月，真实成本差多少

负载稳定就包年包月，付款周期越长折扣越深；只有每月实际运行少于约480小时的临时负载，按量付费才更划算。

以阿里云通用型 g6.large（2核8G，华北3地域）的官方公开报价为例试算：

| 计费方式 | 折合每月 | 相当于目录价的 |
| --- | --- | --- |
| 按量付费（0.35元/小时 × 730小时） | 约255.5元 | 152% |
| 包年包月（月付目录价） | 168元 | 100% |
| 年付 | 142.80元/月 | 85% |
| 3年付 | 92.40元/月 | 55% |
| 5年付 | 63.84元/月 | 38% |

三个数字值得单独说：

- **临界点是480小时**。168元 ÷ 0.35元/小时 = 480小时，摊到每天约16小时。业务每天在线超过16小时，包月就开始省钱；一个每周只跑两天的脚本，按量付费可能只要几十块。
- **长约折扣非常陡**。从月付到3年付，单价打到55折；5年付只要38折，比大多数“优惠活动”实在。
- **按量不是洪水猛兽**。它按实际使用时长计费，弹性扩容、压测、临时环境用它，比预先包月灵活得多。

这套“即用即付 vs 预留折扣”的双轨制是行业通用做法，Azure 的价格页同样是即用即付和预留1年、3年两列，差别主要在折扣深度和最长付款周期。

## 报价表之外的四个变量

表格上的数字不等于最终账单，下面几项都会改写总价。

**地域**。同一配置在香港和新加坡的按量价分别是0.119和0.108美元/小时，新加坡便宜约9%。业务不挑节点时，先比区域价再下单。

**税费和汇率**。Azure 明示价格不含税，跨国交易还受汇率影响。不同厂商报价的含税口径不同，跨境比价时要先还原到同一基准。

**优惠价与目录价**。部分规格同时挂两个价，比如 g5.large 目录月价191元、优惠月价181.45元。比价时看清你看的是哪个价，也别拿优惠月价乘以36去估3年总价——长约是另一套折扣体系（g6.large 的3年付折合每月92.4元，远低于月价乘36）。

**磁盘和带宽的完整核算**。前面说过这两项单独计费，配置越高的盘和带宽对账单影响越明显，下单前把完整配置填进官方报价工具算一遍。

## 常见问题

**价格表里的月价是最终要付的钱吗？**
它只覆盖实例本身。磁盘、公网带宽、快照等另算，部分厂商的价格也不含税，预算要按“实例 + 磁盘 + 带宽”的完整配置算。

**按量付费是怎么计费的？**
按实际使用时长计费，价格表以每小时单价展示，用多久付多久，适合运行时间不可预测的负载。

**SLA 没达到怎么办？**
SLA 是服务商与客户之间的正式承诺，因故障未达到承诺的可用性时，云服务商会按条款提供补偿，具体比例以各家服务协议为准。

**海外节点怎么选更划算？**
同一厂商的不同区域价格不同，不同厂商在同一区域的价差更大。前面香港和新加坡的对比表可以直接当参考，最终以实时报价为准。

## 最后：按你的场景对号入座

- 个人博客、测试环境：包年包月入门规格就够，预算按3年付月价估，2核8G参考约92元/月
- 稳定的生产业务：包月起步，确定用满一年就上年付或更长周期
